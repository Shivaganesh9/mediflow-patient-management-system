# Auth Service

The Authentication Service provides secure user registration, login, JWT-based authentication, refresh-token handling, and role-based authorization for MediFlow.

## Features
- User signup and login
- JWT access token issuance
- Refresh token support
- Role-based authorization
- Swagger UI and OpenAPI docs
- Dockerized deployment

## Technology Stack
- Java 21
- Spring Boot 3.5.x
- Spring Security
- PostgreSQL
- Flyway
- Swagger/OpenAPI
