# MediFlow Patient Management System

MediFlow is an enterprise-grade patient management platform designed for hospitals, clinics, and multi-provider healthcare networks.

## Goals
- Modernize patient workflows with a secure, scalable platform
- Support clinicians, administrators, patients, and billing teams
- Enable event-driven integrations with labs, pharmacies, and insurers

## Tech Stack
- Java 21
- Spring Boot 3
- React + TypeScript
- PostgreSQL
- Apache Kafka
- Spring Cloud Gateway
- Docker

## Repository Structure
- frontend/mediflow-ui: React + TypeScript web application
- backend: Spring Boot microservices
- docs: architecture, API, deployment, and interview documentation
- infrastructure: Docker, Kubernetes, Terraform, and cloud deployment assets
